# helpstudy · 学习长期记忆

建立于2026-10-09，时区 Asia/Hong_Kong。共享仓库：[my_knowledge](https://github.com/Chr0n05-E/my_knowledge)，分支 `main`。

这里由助手整理实际学习进度、疑问与下一步；正式概念笔记和“我的理解”仍由用户在 `notes/` 中主导。讨论过不等于掌握，安排过不等于完成。

## 恢复学习

先同步远端，再读本页、[[helpstudy/学习状态]]、[[helpstudy/后续学习计划]]，按需读取最近日记录。出现实际代码、解释或完成反馈后更新对应记录，并提交推送。操作见 [[helpstudy/GitHub同步约定]]。

| 位置 | 用途 |
|---|---|
| [[helpstudy/学习状态]] | 长期目标、已知进展与理解缺口 |
| [[helpstudy/后续学习计划]] | 下一次接续点与任务池 |
| `daily/` | 按实际学习日期保存证据与复盘 |

## 安排与同步边界

本机每日08:00（Asia/Hong_Kong）的任务已启用；手机旧任务保留，用户拟自行暂停，尚无暂停完成反馈。日计划包含一个最重要任务、一个可选任务和10—20分钟最低完成版，忙碌时可以休息。

电脑、手机或其他会话需要实际读取仓库，具备写权限时才能提交反馈。文件发布不等于手机安装技能，也不意味着所有聊天自动同步。没有新证据就保持待学或待复核状态，不保存凭据或无关私人细节。

本目录可在Obsidian浏览；现有网页构建只扫描 `notes/`。
