## 日常使用

在能访问 `E:\Knowledge` 的对话里，直接说“根据 helpstudy 帮我继续学习”或“把今天的学习更新到 helpstudy”。辅导开始时先恢复状态；出现新代码、新解释、练习反馈或明确的新兴趣时，再更新日记录与计划。只追加实际发生的内容，不提前生成“已学完”的日记。

知识库根目录的 `AGENTS.md` 已约定学习任务的读取和更新方式。[官方说明](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra)介绍了项目级 AGENTS.md 的作用。此机制需要会话能够访问该目录；其他云端或普通聊天不会因此自动取得这些文件，也不会在没有运行任务时后台同步。

## 记录标准

| 标记 | 含义 |
|---|---|
| 有完成证据 | 用户提交实现或明确完成练习；不等于长期熟练 |
| 有理解证据 | 用户用自己的话解释、回答问题；保留错误与限定 |
| 已讨论 | 助手讲解过，尚缺独立输出 |
| 待复核 | 正文缺失、理解仍有疑问或需要新练习 |
| 待学 / 建议 | 未来任务，尚未完成；建议不等于用户承诺 |

采用实际发言或练习时间归档，不按对话最后更新时间推断学习日期。助手补充的知识说明要明确标注，不将其写成用户原话。

定时任务需要遵循：安排学习前读取本目录的 README、学习状态、后续学习计划和最近实际存在的日记录；根据长期目标、未完成事项、理解缺口、兴趣和设备条件，提出一个最重要任务、一个可选任务和一个10—20分钟最低完成版，忙碌日可安排休息。不要重复布置已完成的同一练习，也不要把安排视为完成。如果无法读取本地文件，明确说明限制及所依据摘要的日期。

本地运行需要能够访问 `E:\Knowledge`；网页或云端任务不能仅凭路径读取本机目录，需要可访问的上传材料或连接服务。[定时任务官方说明](https://learn.chatgpt.com/docs/automations)
