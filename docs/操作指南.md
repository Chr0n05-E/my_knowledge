# 知识库操作参考

安装、启动和基本用法见 [README](../README.md)。这里补充字段、关系和图谱操作。

## 新建笔记的参数

| 参数 | 用途 |
|---|---|
| `<id>` | 相对 `notes/` 的路径，不含 `.md`；用 `/` 分层 |
| `--title` | 显示标题，默认取 ID 的最后一段 |
| `--type concept` / `--type domain` | 概念或领域，建议显式指定 |
| `--parent <id>` | 增加父节点，可重复指定 |
| `--status seed` / `growing` / `evergreen` | 笔记状态，默认 `seed` |
| `--tags a,b` | 逗号分隔的标签 |
| `--force` | 覆盖已有文件，原内容会被替换 |

未指定类型时，`new.py` 将无斜杠的 ID 视为领域，带斜杠的 ID 视为概念。创建子领域时需要写 `--type domain`。

## Frontmatter

```yaml
---
id: math/algebra/group_theory
title: 群论
type: concept
parents: [math/algebra]
aliases: [Group Theory]
tags: [代数]
status: seed
created: 2026-10-14
updated: 2026-10-14
relations:
  前置: [math/algebra]
---
```

以上是格式示例；关系目标必须存在于实际笔记中。

| 字段 | 说明 |
|---|---|
| `id` | 与文件路径一致；不一致时构建会警告，以路径为准 |
| `title` | 显示标题，也用于解析双链 |
| `type` | `concept` 或 `domain`；仅概念笔记检查必要章节 |
| `parents` | 多父归属，首个父节点应与目录层级一致 |
| `aliases` | 双链可以使用的别名 |
| `tags` | 搜索和标记 |
| `status` | 笔记状态标记 |
| `created` / `updated` | 新建时填写，后续修改由用户维护 |
| `relations` | 类型化关系，也可以改用正文标签行 |

## 关系与图片

文件夹决定基本从属关系。其他关系在正文行首写标签和双链，可带列表前缀：

```markdown
- 前置：[[math/algebra|代数]]
- 对比：[[另一个概念的ID]]
- 应用于：[[应用的ID]]
```

| 关系 | 常用标签 |
|---|---|
| 从属 | 属于、上级、交叉归属、parent |
| 前置依赖 | 前置、依赖、先修、prerequisite |
| 推广 / 特例 | 推广、推广自、特例、extends |
| 应用于 | 应用、应用于、用于 |
| 引用 | 引用、参考、出处 |
| 对比 / 易混 | 对比、易混、区别、反例 |
| 相关 | 相关、参见、另见 |

未写标签的双链按“相关”处理。双链按 ID、标题和别名解析；代码块和行内代码中的双链不参与解析。

关系类型、别名、颜色、线型和方向由 [kb.config.yml](../kb.config.yml) 定义。从属边默认由父指向子；`arrow_dir: source` 可以反转某种关系的箭头位置。

图片可以写成 `![](attachments/example.png)`（相对当前笔记）或 `![[example.png]]`（在 `notes/` 中按文件名查找）。构建时会复制到 `out/assets/`。

## 图谱操作

网页顶部可以切换笔记与图谱，搜索支持标题、ID、标签、别名和正文。图谱支持缩放、拖动、按领域或关系类型筛选，以及聚焦选中节点的邻居。

| 网页地址参数 | 效果 |
|---|---|
| `index.html#节点ID` | 打开指定笔记 |
| `index.html?view=graph` | 打开图谱 |
| `index.html?view=graph&layout=force` | 使用力导向布局 |
| `index.html?view=graph&dir=v` | 使用纵向层次布局 |
| `index.html?focus=节点ID` | 聚焦指定节点 |

图形界面的“图谱”页使用层次布局。右键节点可新建子领域或概念、打开笔记、复制 ID 或聚焦邻居；右键空白处可新建顶层领域。

## 常见问题

| 问题 | 处理 |
|---|---|
| 网页未显示最新笔记 | 重新运行 `python tools/build.py` |
| 链接或关系目标不存在 | 修正目标 ID，或新建对应笔记 |
| 缺少“我的理解”章节 | 在概念笔记中补充该章节；检查不判断是否掌握 |
| 目录上级没有笔记 | 为父节点新建 `type: domain` 的笔记 |
| 父子关系成环 | 检查目录和 `parents`，移除循环归属 |
| 标题重复 | 修改标题或使用明确的 ID 链接 |
| 自定义关系不生效 | 确认当前 Python 环境已安装 PyYAML，再检查配置 |
| 公式显示为原始文本 | 检查网络，KaTeX 从 CDN 加载 |
| 图片缺失 | 检查笔记内路径和构建报告 |
| 某种关系未出现在图例中 | 图例只显示当前数据使用的关系类型 |
| `--domain` 参数报错 | 改为 `--type domain` |
| 找不到 `python` | 安装 Python 并加入 PATH，或使用解释器完整路径 |
